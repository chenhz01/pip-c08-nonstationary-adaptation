# Learning Cards

Each card has four layers: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Plus the gap evidence.

---

## 非平稳适应

> 环境变了，旧经验还在生效，而且它不知道要重学。

### L29 · 换档检测

`drift-regime-detector` · `components/L29-drift-regime-detector/`

- **L0（人话）** 世界变了，你的老经验就不管用了。这工具能看出「世界变了」这件事，而不是把它当成运气差。
- **L1（本质）** 比较两段窗口的均值与方差，算 pooled z 与方差比，任一超阈即判 shift。关键区分：均值动（目标变了）vs 波动动（环境变吵），两者处置不同。
- **L2（怎么用）** 每周比一次本周与上周；判 shift 就把旧阈值全部作废重标，别硬调。
- **边界** 每段至少 3 个样本；窗口太小会把噪声当换档。
- **空白证据** 变点检测算法成熟（CUSUM 等），缺「工程化判定 + 给动作」的 30 行版本（抽样未单列）。

### L30 · 适应速率闸

`adaptation-rate-governor` · `components/L30-adaptation-rate-governor/`

- **L0（人话）** 碰上一次倒霉事，就改掉全部做法，是过度反应。这工具给新经验设权重上限。
- **L1（本质）** 权重 = n/(n+k)（k=10 作先验强度），并封顶 0.5。它防的是「用一个坏样本改掉整套经验」——这在非平稳环境里是最常见的自伤。
- **L2（怎么用）** 拿到 weight_new <0.3 就继续沿用旧结论，同时把这个新样本挂进观察名单。
- **边界** 先验强度 k=10 是默认值；高风险场景应调大。
- **空白证据** 在线学习有学习率调度，缺「面向决策规则的保守更新闸」（抽样未单列）。

### L31 · 冻结基线守卫

`frozen-baseline-guard` · `components/L31-frozen-baseline-guard/`

- **L0（人话）** 最危险的不是改坏了，是「偷偷把及格线调低」然后宣布进步。这工具能抓住这件事。
- **L1（本质）** 基线内容 crc32 指纹 + 版本号双锁。内容变了而版本没变 → tampered（红旗）；版本升了且有批准 → approved-change。
- **L2（怎么用）** 基线建立时封一次；每次报告前核一次，tampered 一律不许发布。
- **边界** 只管「改没改」，不管「改得对不对」。
- **空白证据** 模型评测有基准污染问题，但缺「基线文件级防偷改」的守门器（抽样未单列）。

### L32 · 元搜索预算

`meta-search-budget` · `components/L32-meta-search-budget/`

- **L0（人话）** 有四个方案，钱只够认真试两个。这工具的做法是：先都粗略试一遍，砍掉一半，再认真试剩下的。
- **L1（本质）** successive halving：每轮均分预算 → 按分保留一半 → 重复。它的价值不是找最优，而是「用固定预算先把不可信的杀掉」，避免在明显差的方案上烧完钱。
- **L2（怎么用）** 候选 ≥4 时用；每轮把实测分写回，别拿先验分一直排。
- **边界** 假设候选可分高低；分数噪声大时会误杀。
- **空白证据** 超参搜索有 Hyperband，缺「面向 agent 架构候选、带淘汰日志」的轻量版（抽样未单列）。
